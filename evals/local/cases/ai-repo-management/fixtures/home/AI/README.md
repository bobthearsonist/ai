# Synthetic AI toolkit

`scripts/sync.sh` reads `local.yaml` collections and `external-skills.yaml`.
Generated `skills/` and `agents/` contain links, not canonical private sources.
The private source repository is `~/Repositories/ai-private`.
Read `docs/collections.md`, `docs/skills-agents-architecture.md`, and the registries.
Synchronization is local discovery; publishing a plugin is a separate operation.
The evaluation provides documentation, not an executable sync script.
